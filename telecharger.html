Installer et activer

  1. Lancez le fichier téléchargé

    Double-cliquez sur ConformCL-Mines-Installation-1.1.0.exe, dans votre dossier Téléchargements.

  2. Si Windows affiche « Windows a protégé votre ordinateur »

    Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

    Le logiciel est signé numériquement au nom de l'éditeur Alhassane Sow (certificat Certum). Ce message peut encore apparaître tant que le logiciel est récent et peu connu de Microsoft. Il ne signale pas de virus. Vérifiez que la fenêtre indique « Éditeur : Alhassane Sow ». Si elle indique « Éditeur inconnu », ne lancez pas le fichier et contactez-nous.

  3. Suivez l'assistant d'installation

    Lisez et acceptez les conditions de licence, choisissez le dossier d'installation si vous le souhaitez, puis cliquez sur Installer. Aucun droit administrateur n'est nécessaire.

  4. Notez votre code poste

    Au premier lancement, acceptez les conditions d'utilisation. L'écran d'activation affiche alors votre code poste, au format XXXX-XXXX-XXXX-XXXX.

  5. Envoyez-nous ce code

    Transmettez-le par courriel avec le nom de votre société. Nous vous renvoyons votre clé de licence, qui commence par CCLM1.

  6. Collez la clé dans l'écran d'activation

    Le logiciel est prêt. Le nom de votre société apparaît dans l'en-tête. Pour renouveler votre licence, il suffira de coller une nouvelle clé au même endroit.

Vérifier que le fichier est authentique

Le plus simple : clic droit sur le fichier, Propriétés, onglet Signatures numériques. Le signataire doit être « Alhassane Sow ».

Pour une vérification complète, ouvrez une invite de commandes sur votre dossier Téléchargements et lancez :

certutil -hashfile ConformCL-Mines-Installation-1.1.0.exe SHA256

Le résultat doit être identique à l'empreinte ci-dessous. S'il diffère, ne lancez pas le fichier et contactez-nous. Pour la version portable, remplacez le nom du fichier dans la commande.
