Données et sécurité

Vos données restent dans votre entreprise

ConformCL Mines est un logiciel Windows installé sur vos postes. Les informations sur votre personnel, vos achats et vos fournisseurs ne quittent pas votre ordinateur.

  • Stockage local. Les données sont enregistrées sur le poste, sans serveur externe.
  • Enregistrement automatique. Le brouillon est sauvegardé sur disque et résiste à une coupure de courant.
  • Registre et sauvegardes. Historique des dossiers, recherche, sauvegarde et restauration dans un fichier unique.
  • Logiciel signé. Les fichiers d'installation portent une signature numérique Certum au nom de l'éditeur.
  • Licence vérifiée hors ligne. Aucune connexion Internet n'est nécessaire pour utiliser le logiciel.
Démarrer

Opérationnel en quelques minutes

  1. Téléchargez

    L'installateur Windows, ou la version portable pour un poste verrouillé.

  2. Installez

    Sans droits administrateur. Raccourcis sur le bureau et dans le menu Démarrer.

  3. Envoyez votre code poste

    Il s'affiche au premier lancement. Vous recevez en retour votre clé de licence.

  4. Renseignez votre projet

    Fiche projet, puis contrôles. Importez vos tableaux Excel existants si vous en avez.
